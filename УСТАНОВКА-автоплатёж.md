# Установка: автопродление (визуальный режим) + сброс трафика по дате создания

Патч `autopay-visual-v3.patch` накладывается на твой сервер, где уже применён
прошлый патч (от Sonnet). Бот стоит в `~/remnawave-shopbot`, запуск через Docker
Compose, база `users.db` в каталоге проекта — при обновлении **не трогается**.

Что даёт патч:
- **Автопродление** — в меню ключа кнопка **🔄 Автопродление: вкл/выкл**.
  Переключение мгновенное, **без обращения к ЮKassa/ЮMoney и без списаний**
  (визуальный статус). Обычные платежи не затрагиваются.
- **Сброс трафика по дате создания** — нативная стратегия Remnawave
  `MONTH_ROLLING` в выборе стратегии хоста.

---

## Шаг 1. Закинуть патч на сервер

С компьютера, где скачан `autopay-visual-v3.patch`:

```bash
scp autopay-visual-v3.patch root@ТВОЙ_СЕРВЕР:~/remnawave-shopbot/
```

---

## Шаг 2. Бэкап и наложение патча

```bash
cd ~/remnawave-shopbot

# 1. Резервная копия базы
cp users.db users.db.bak-$(date +%F)

# 2. Проверка, что патч ляжет чисто
git apply --check autopay-visual-v3.patch && echo "OK, можно применять"

# 3. Применение
git apply autopay-visual-v3.patch
```

Если шаг 2 выдал ошибку — пришли разработчику вывод:
```bash
git status && git log --oneline -3
```

---

## Шаг 3. Пересобрать контейнер

```bash
sudo docker-compose down
sudo docker-compose up -d --build
sudo docker-compose logs -f --tail=50
```

Дождись, что бот и вебхук поднялись, затем `Ctrl+C`.

---

## Шаг 4. Включить в веб-панели

1. **Настройки → Платёжные системы** → YooKassa → включить
   **«Автоплатёж (рекуррент)»** → Сохранить. Это включает показ кнопки
   автопродления в меню ключа.
2. **Настройки → Хосты → Сброс трафика** → выбрать
   **«Ежемесячно (по дате создания)»** → Применить (для каждого хоста).

---

## Как работает автопродление сейчас

- В меню ключа кнопка **🔄 Автопродление: выкл** → нажатие →
  **🔄 Автопродление: вкл ✅** и обратно.
- Никаких платежей и списаний — только визуальный статус.
- Реальная логика автосписания (с баланса / по карте) сохранена в коде
  (`charge_key_autopay` в `handlers.py`), но **не вызывается**. Чтобы включить
  реальные автосписания позже, нужно снять ранний `return` в функции
  `_maybe_process_autopayments` (файл `src/shop_bot/data_manager/scheduler.py`).

---

## Откат

```bash
cd ~/remnawave-shopbot
git apply -R autopay-visual-v3.patch
cp users.db.bak-ГГГГ-ММ-ДД users.db   # если правил базу
sudo docker-compose up -d --build
```
