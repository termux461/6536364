# Установка: автоплатёж + сброс трафика по дате создания

Инструкция по наложению патча `autopay-monthreset.patch` на уже установленного
бота remnawave-shopbot (Ubuntu, запуск через Docker Compose).

Бот стоит в `~/remnawave-shopbot`, база `users.db` лежит в каталоге проекта и
при обновлении **не трогается**.

---

## Шаг 1. Закинуть патч на сервер

С компьютера, где скачан `autopay-monthreset.patch`:

```bash
scp autopay-monthreset.patch root@ТВОЙ_СЕРВЕР:~/remnawave-shopbot/
```

Если заходишь не под root — подставь своего пользователя и путь до бота.

---

## Шаг 2. Бэкап и наложение патча

```bash
cd ~/remnawave-shopbot

# 1. Резервная копия базы
cp users.db users.db.bak-$(date +%F)

# 2. Проверка, что патч ляжет чисто (ничего не меняет)
git apply --check autopay-monthreset.patch && echo "OK, можно применять"

# 3. Применение
git apply autopay-monthreset.patch
```

### Если шаг 2 выдал ошибку `patch does not apply`

Значит локальный код разошёлся с чистым 1.5.7. Применяй с отчётом об отказах:

```bash
git apply --reject --whitespace=fix autopay-monthreset.patch
find . -name '*.rej'      # посмотреть, что не легло
```

Если появились файлы `*.rej` — пришли их содержимое разработчику, дожать вручную.

---

## Шаг 3. Пересобрать контейнер

```bash
sudo docker-compose down
sudo docker-compose up -d --build
sudo docker-compose logs -f --tail=50
```

Дождись, что бот и вебхук-сервер поднялись, затем `Ctrl+C`.
Новые колонки в БД (`autopay_*`, `yookassa_payment_method_id`) добавляются
автоматически при старте — миграция встроена.

---

## Шаг 4. Включить в веб-панели

1. **Настройки → Платёжные системы**, блок YooKassa →
   тумблер **«Автоплатёж (рекуррент)»** → Сохранить.
2. **Настройки → Хосты → Сброс трафика** →
   выбрать **«Ежемесячно (по дате создания)»** → Применить (для каждого хоста).
3. В кабинете ЮKassa проверить, что вебхук указывает на
   `https://ТВОЙ_ДОМЕН:ПОРТ/yookassa-webhook` и событие `payment.succeeded` включено.

---

## Как это работает после установки

- В меню каждого ключа появляется кнопка **🔄 Автоплатёж**.
- **Привязка карты** — списывается 10 ₽ (для сохранения карты) и сразу
  возвращается обратно. Карта сохраняется для автосписаний.
- **Автопродление** за ~24 ч до конца подписки: сначала пытается списать
  с внутреннего баланса, при нехватке — с привязанной карты. При неудаче
  пользователь получает уведомление с кнопками продления и пополнения.
- **Оплата с баланса** тоже включает автоплатёж (если карта уже привязана).
- **Сброс трафика** — нативная стратегия Remnawave `MONTH_ROLLING`: панель
  сама обнуляет трафик в число создания пользователя.

---

## ⚠️ Важно

- **Рекуррентные платежи должны быть разрешены на стороне ЮKassa.** Без этого
  сохранение карты вернёт ошибку — запросить включение у поддержки ЮKassa.
- **Не запускать официальный `install.sh` в режиме обновления после патча** —
  он делает `git reset --hard origin/main` и сотрёт изменения (база уцелеет,
  т.к. не в git). Для обновления с оригинала: обнови, потом наложи патч заново.
- Уже существующие ключи получат стратегию `MONTH_ROLLING` при следующем
  продлении, либо выставь её вручную в панели Remnawave.

---

## Откат

```bash
cd ~/remnawave-shopbot
git apply -R autopay-monthreset.patch        # снять патч
cp users.db.bak-ГГГГ-ММ-ДД users.db          # вернуть базу (если правил)
sudo docker-compose up -d --build
```
